# divya-data-trail · site source

Next.js (static export) source for https://divyabomaraboina.github.io/divya-data-trail/

```bash
npm install
npm run dev                                   # local preview at http://localhost:3100
BASE_PATH=/divya-data-trail npx next build    # builds the static site into out/
```

To publish, copy the contents of `out/` to the repo root (keep `site/`), commit and push to `main`.
